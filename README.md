## 🧠 About the journal system

This repository uses a **dual-branch model**:

- `main` → professional, public-facing engineering work
- `journal` → private operational cockpit (daily logs, XP, metrics, reflections)

The journal branch contains:
- daily engineering logs
- weekly and monthly reviews
- gamification and XP tracking
- personal learning analytics

This separation keeps the public portfolio clean while allowing deep self-tracking and meta-cognition.
